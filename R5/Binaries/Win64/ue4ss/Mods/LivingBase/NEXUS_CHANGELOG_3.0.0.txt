Living Base Enhanced v3.0.0 (previous version on Nexus: v2.1.7.1) -- MAJOR REWORK

This release changed enough that it's easier to treat as a new baseline than as an incremental diff. Full breakdown in the shipped README.md; highlights below.

===== NUMPAD-ONLY CONTROLS, GUI-ONLY SPAWNING =====

Every keyboard-only spawn/decoration/live-edit key from earlier versions is retired. The GUI window (open with Numpad Minus) is now the only way to spawn, replace, or customize anything. The numpad works identically in-game or with the GUI focused, for movement, confirmation, despawn, and undo.

===== TWO NEW GUI TABS: CUSTOMIZE AND PHOTO MODE =====

- Customize: spawn a from-scratch custom character (pick a sex, Body Type, and Origin), then dress and pose ANY target-locked actor -- Body (skin tone, eye color, physique, height, AI toggle, one-way "Make Ghost"), Hair, Clothes (with a toggleable fit-safety net), Belts and Straps (plus accessory detect/randomize), and Poses and Actions. "Read Current" reads a target's live look into every control; "Save Customizations" pins the current setup so it survives a reload.
- Photo Mode: camera positioning presets, a directional move pad, target highlight, and a precise coordinate editor, plus a 3-slot portable lighting rig (color/brightness/throw per slot), for setting up screenshots.

===== APPEARANCE NO LONGER LOCKS IN PERMANENTLY BY DEFAULT =====

Most rosters now regenerate a fresh randomized look on every world reload -- same as a brand-new spawn -- instead of permanently keeping whatever was rolled the first time. Use "Save Customizations" on a specific actor if you want to keep its exact current appearance.

===== SENKAMATI: NEW "ORIGINAL UPRIGHT" PRESENTATION, PLUS A CURATED LEGS FIX =====

Every Senkamati archetype (Warrior, Hunter, Thrall, Caster) now has two full presentations -- the original "Wild" crew-based re-skins, and a new "Original Upright" using the native mob body with an upright walking gait (cosmetic only, can't fight with real weapons). Both are organized Mask On/Off with a moving and frozen "Idle" version of every entry, and both correctly restore mask/weapon/idle state on a world reload. Caster/Hunter/Thrall's "Wild" mask-off look also gets a specific curated Legs piece + color instead of showing plain default underwear.

===== ANIMALS: EVERY LOOK NOW HAS A FROZEN "(IDLE)" VERSION =====

Boars, goats, dodos, wolves, crocodiles, and crabs each get a wandering "(Mobile)" and a frozen, statue-like "(Idle)" version of every individual look.

===== NEW GUI TAB: TARGET LIST =====

Scans tracked actors within a chosen radius (3/5/8/10/15m), filtered by People/Monsterous/Animals/Decor checkboxes, and lists them nearest-first with a small "+" button to target-lock any one directly -- unlike Numpad+, this can lock something out of view entirely, to help find it if you don't know where it is. Shows a large live-updating distance readout for whatever's currently locked, and a "+/-" lock/release button next to Selected Target, matching the other tabs.

A new "Mark Target" checkbox on this tab highlights whatever's currently locked -- a glowing marker material for decor, or a following flame-ring effect for people/animals/monsters that tracks the target as it moves. Clears automatically when unchecked or when nothing's targeted.

===== FIXED =====

- Several world-reload bugs found building the above: an "Idle" actor silently un-freezing a few seconds after restore; a new roster misidentified by an older restore rule sharing the same native class; a restored Thrall being misidentified as a Warrior.
- The GUI window no longer confuses Steam's F12 screenshot / FPS counter -- it now waits a few seconds before creating its own render device, so the game's real one gets recognized first. The window takes a moment to appear after loading; this is expected.
- Live-edit movement now moves any character (not just statues) relative to its own facing direction -- Senkamati crew and named NPCs previously moved along a fixed world axis instead, the same as decor.

===== RESTORED =====

- Structure shield: building blocks are invulnerable to damage again (on by default -- config.txt toggle), independent of the old Blackbeard raid feature it originally shipped alongside. Protects the base from ordinary hostile mobs, applied instantly to newly-placed blocks and swept over the base shortly after each load.

Everything from the previous preview/relocate/statue-targeting rebuild and the first "Custom" GUI category also ships in this release, superseded in UX by the Customize tab above but unchanged in underlying behavior.
