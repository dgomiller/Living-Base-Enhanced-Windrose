[size=5][b]Living Base Enhanced[/b][/size]
[color=#D4D4D8]A base-building and population toolkit for Windrose — hand-place ambient NPCs, animals, posed statues, and decorations anywhere around your base, fine-tune each piece in place (full X/Y/Z position and rotation), and have it all persist across reloads. The primary way to do all of this is a real clickable GUI window — press '-' in-game to open it — with every keyboard control still fully available alongside it.[/color]

[size=4][b]What's new in 2.1.0[/b][/size]
[color=#D4D4D8]
[b]Full 3-axis rotation[/b] — the GUI's move panel and Coords window can now rotate a placed object around all three axes (X/Y/Z = Roll/Pitch/Yaw), not just spin it around its vertical axis. Useful for anything that can rest at any angle — a dropped weapon, a coin, an ingot — not just statues/NPCs, which only ever needed the one. The move panel's old single Rot L/R + Flip 180 are now three full rows, each with its own Left/Right button; the Coords window's single "Rotation" field is now Rotation X/Y/Z. Keyboard ',' '.' stay the only two rotate keys — '/' (the plain key next to '.', not the numpad one) cycles which axis they act on, from either the game or the GUI window, toast-confirmed each press — both input paths share the exact same selection, so they can never disagree.

[b]Drops[/b] — a new decor category: 18 hand-picked themed groups (Animal Parts, Artifacts, Clothes, Currency, Ingredients, Keys, Meals, Mined, Misc, Potions/Bottles/Healing, Seeds, Tailoring, Tools, Treasure, Trophies, Weapons, Wood, Writings) covering everything from weapon and armor pieces to currency, ingredients, and treasure. Every entry has a real display name (e.g. "Bezoar," not "Loot_T02_Bezoar_01") in both the GUI tree and its on-screen toast. Browsable in the GUI's spawn tree, or by cycling the ' key in-game.

[/color]

[size=4][b]The GUI[/b][/size]
[color=#D4D4D8]LivingBaseSpawnMenu, a second, compiled companion mod bundled with this download, adds an always-on-top, clickable window instead of keyboard-only cycling. Every keyboard control still works exactly as before — the GUI is an additional, faster way to reach the same rosters, not a replacement.[/color]

[color=#D4D4D8]
[b]A categorized spawn tree[/b] — every roster (crew, statues, Senkamati, decor, animals, walking women, and more) laid out as a browsable, clickable tree instead of "press a key and cycle." Click an entry, then Spawn a new copy or Replace whatever's currently target-locked with it — no more stepping through a roster one press at a time to find the one you want.

[b]A real held-repeat move panel[/b] — Forward/Left/Right/Backward/Up/Down and full X/Y/Z rotate as actual UI buttons you can hold down for continuous movement, sidestepping this UE4SS build's well-known "most rapid repeat keypresses get dropped before the mod ever sees them" limitation on the equivalent keyboard keys.

[b]A precise coordinate editor[/b] — type exact X/Y/Z position and X/Y/Z rotation for whatever's target-locked, with Preview (try it live), Apply (commit), Reset, and Cancel (both revert to however it was when the editor opened).

[b]In-window Instructions and History tabs[/b] — the full control reference and a running log of every on-screen toast this session, both readable without alt-tabbing out.

[b]Two always-available keys[/b] — '-' opens/closes the GUI window from anywhere while playing (starts closed each session); '=' steals OS focus for it once it's open, so your next click lands there without an extra click first.

[b]In-Game Keys, narrowed in scope[/b] — the on/off master toggle (Insert) controls ONLY LivingBase's own keyboard keys (placement, live-edit, cycle, clear); the GUI's own buttons are independent of it by design, since the GUI is the primary way to use the mod. Off by default each session.

[b]Unique per-placement names[/b] — every object you place gets its own distinguishable name (e.g. "Brethren Woman 1", "Brethren Woman 2") instead of every copy of the same look sharing one identical label. Stored in your save, so names stay stable across reloads.
[/color]

[size=4][b]The full toolkit[/b][/size]
[color=#D4D4D8]
[b]Real Undo (Num 0)[/b] — restores the last despawned object (or an entire Delete wipe, as one batch) at its exact spot, including AI/composite-look appearance where recorded. Steps back through your last 20 actions.

[b]Cycle statues AND decorations (] and [)[/b] — swap the targeted statue or decoration for the next (or previous) entry in its own roster, in place, without re-placing it from scratch. One key pair auto-detects which kind you're targeting. Undo-able with Num 0, which names what it restored on-screen.

[b]Generalized quest NPCs[/b] — named quest NPCs (Letty, Francois Arno, and more) become plain ambient set-dressing when placed with this mod, instead of keeping their live quest dialogue and interact prompt.

[b]Faction leaders & walking faction visitors[/b] — named NPCs (Benjamin Hornigold, Henri Boucher, Marita Suares, Long Ben, Charlie Sharp) on the standing statue roster, plus 15 more standing/seated/interactive poses that shipped with the game but were never wired in. Crew (Num 1) cycles through 14 looks per press: the default crew look, plus 12 walking re-skins covering all four factions (Buccaneers, Smugglers, People of Tortuga, Brethren of the Coast) in Musketeer/Sailor/Sergeant variants, plus a Brethren of the Coast woman look — real crew pawns with working walk AI, not statues.

[b]Normal-posture Senkamati and a big animal roster[/b] — the Senkamati Hunter and Caster (Num 7) walk with normal human posture instead of their native mob's lumbering gait, matching the Warrior. Num 7 cycles through 30+ looks: original mob body vs. re-skinned, with or without the tribal helmet, each one's untouched "as original" corrupted appearance, and a frozen/idle counterpart for every look — the female Caster's re-skin comes in two different base bodies (Gatherer and Herbalist) with distinct figure/hair-color/palette. Farm animals (Num 8): 13 entries — Goat Mega, Sow, Charging Boar, Boar Mega, Wolf, Alpha Wolf, Crocodile, and a corrupted "Plague" Crocodile alongside the boar/goat/dodo set, all tamed and friendly.

[b]Walking Women (Numpad . key)[/b] — a real, walking female NPC re-skinned to look like Letty, Marita Suares, or the Buccaneers Merchant, plus two plain looks ("Woman With Hat" and "Woman With Hair") for general crowd variety. Every look comes in TWO different base bodies (Base 1/Base 2, genuinely different figures and hair color via two different underlying NPC classes, same outfit/hair-style either way) for 10 stops total. Every placement rolls a random skin tone (and, for the plain looks, a random hairstyle) — this re-rolls each time you reload your save, on purpose. Reloading correctly restores which look/character/base each placed NPC was.

[b]Reticle-accurate targeting[/b] — despawn, live-edit, and pose-cycle pick the object your camera is actually pointed at (including up/down — you can target two things stacked vertically), instead of a wide "anything vaguely in front of your character's body" guess.

[b]Camera-relative placement[/b] — new spawns appear in the direction your camera is looking (horizontally), not just where your character's body happens to be facing, so free-looking in third person actually matters.

[b]Fixed 45°/180° rotate (Num / and Num *), a precision cycle (Num -), and a target lock (Num +)[/b] — finer live-edit control without needing to spam the regular rotate keys, plus a way to pin despawn/cycle/live-edit to one object so you can walk around it or look away without losing your target.

[b]One key freezes the mod's keyboard keys (Insert)[/b] — toggles LivingBase's own keys (numpad, ;/', Delete, backslash, live-edit) on/off at runtime, so they're free for other uses without editing config files. Starting state is configurable; defaults OFF, since the GUI is the primary workflow.

[b]Real on-screen toast feedback[/b] — despawn, undo, cycle, and spawn actions confirm on-screen, not just in the log, by reusing the game's own native notification widget. World load shows staged progress too: waiting for you to move, restoring your base, and a final summary once it's done. Deliberately quiet where a toast would just be spam — live-edit nudges and "nothing there" misses stay log-only.

[b]No more duplicate spawns on load[/b] — every mod key and the GUI's buttons are locked from the moment a world load starts until your base finishes restoring, so nothing you place manually in that window gets saved and then restored a second time.

[b]Decorations off the F-row (; and ')[/b] — decoration placement never touches F1-F6, for compatibility with other mods that use F-Keys. ' cycles which decoration category is active (with an on-screen message telling you which one), and ; places from whichever category that is.

[b]Per-world saves[/b] — if you play more than one Windrose world, each one keeps its own separate base save automatically.
[/color]

[size=4][b]Installation[/b][/size]
[color=#D4D4D8]1. Install UE4SS (latest experimental / RE-UE4SS build) into Windrose. In ue4ss\UE4SS-settings.ini, under [EngineVersionOverride], set MajorVersion=5 and MinorVersion=6. The mod will not load without this override.

2. Extract the download so BOTH mod folders sit at:
...\Windrose\R5\Binaries\Win64\ue4ss\Mods\LivingBase\
...\Windrose\R5\Binaries\Win64\ue4ss\Mods\LivingBaseSpawnMenu\
(you should have ...\Mods\LivingBase\Scripts\... and config.txt inside the first one, and ...\Mods\LivingBaseSpawnMenu\dlls\main.dll inside the second).

3. Enable both: open ...\ue4ss\Mods\mods.txt and add the lines:
LivingBase : 1
LivingBaseSpawnMenu : 1

4. Launch the game, load into a world, and press '-' to open the GUI (or use the keyboard controls below directly).

Optional: edit LivingBase\config.txt (plain text, no coding) to toggle features.
Back up your saves before first use — standard caution for an Early Access game with unofficial mods.[/color]

[size=4][b]Main Features[/b][/size]
[color=#D4D4D8]
[b]GUI window (LivingBaseSpawnMenu)[/b] — a categorized, clickable spawn tree; a held-repeat move/edit panel with full X/Y/Z rotation; a precise typed coordinate editor; in-window Instructions/History reference. Open/close with '-', steal focus for it with '='.

[b]Placement toolkit[/b] — drop one actor or prop per pick (GUI) or keypress (keyboard), ~3m ahead in the direction you're looking:
- Numpad 1-9: crew (cycles 14 looks, including faction-visitor re-skins), townsfolk, four kinds of posed statue, friendly Senkamati tribals, friendly wildlife, and despawn.
- Numpad . (decimal): a walking female NPC, cycling through Letty, Marita, the Buccaneers Merchant, and two plain looks.
- ' (apostrophe): change the active decoration category (nature, boats, wrecks, tents, storage, furniture, plus 18 Drops themes). ; (semicolon): place from the active category.
- Num 0: undo the last despawn/wipe/pose-cycle. ] and [: cycle a statue or decoration's pose forward/backward. Backslash: flip statue facing for future spawns.

[b]Live-edit[/b] — nudge the nearest placed piece (or, via the GUI, the target-locked one) and the change persists: PageUp/PageDown height, comma/period rotate whichever axis is selected ('/' switches axis), arrow keys slide, Num / and Num * for fixed 45°/180° yaw, Num - cycles precision, Num + toggles a target lock. Targeting tracks your camera, not just your body facing.

[b]Persistence[/b] — everything you place is saved and restored on the next world load, separately per world if you play more than one, each with its own unique per-placement name and full position/rotation. Delete (pressed twice), or the GUI's Delete All, clears everything in the current world.

[b]In-Game Keys toggle[/b] — Insert freezes LivingBase's own keyboard keys (numpad/;/'/etc.), independent of the GUI, which keeps working either way. Off by default each session.

[b]Whistle crew escort[/b] — use the boar whistle to summon a small crew squad that follows you and fights at your side.

[b]Invulnerable structures[/b] — your building blocks are made damage-proof so raiders can't wreck the base.

[b]Unlock hidden build pieces[/b] — surfaces build-menu pieces hidden from standard play, while leaving recipe-locked progression intact.

Every feature is individually toggleable in config.txt.
[/color]

[size=4][b]Controls[/b][/size]
[color=#D4D4D8]NumLock must be ON for the numpad keys to register. Everything below also works, or has an equivalent, in the GUI window (see What's New above) — press '-' to open it.[/color]

[color=#D4D4D8][b]Numpad[/b] — place NPCs, statues & animals (one per press, ~3m ahead in your camera direction; statues face you):
Num 1 — Crew pawn (wanders; fights hostiles as a combat ally; cycles 14 looks — default crew, plus 12 walking faction-visitor re-skins across Buccaneers/Smugglers/People of Tortuga/Brethren of the Coast, plus a Brethren of the Coast woman)
Num 2 — Townsman (wanders; sits on chairs/benches/beds)
Num 3 — Standing statue (merchants, chatting, cross-arms, women, quest folk, named faction leaders — cycles)
Num 4 — Floor sitter (cycles)
Num 5 — Chair/stool sitter: place your own stool (cycles)
Num 6 — Interactive statue: rummaging a chest/table, warming by a fire (cycles)
Num 7 — Friendly Senkamati tribal human: Warrior, Hunter, and female Caster — 30+ looks total (with/without helmet, original mob body vs. re-skinned where applicable — the female Caster's re-skin has two base bodies with distinct figure/palette — plus each one's original corrupted look. Every look also has a frozen/idle counterpart — cycles)
Num 8 — Friendly wildlife: boar family / goats / dodos / wolves / crocodile (cycles)
Num 9 — Despawn the object in front of you, on your floor
Num 0 — Undo: restore the last despawn (or a whole Delete wipe) at its exact spot, appearance included; names what it restored
Num . (decimal) — Walking female NPC: cycles Woman With Hat, Woman With Hair, the Buccaneers Merchant, Letty, and Marita — each with a randomized skin tone (and, for the two plain looks, hairstyle) on every placement
Backslash (\) — Flip statue facing 180° for future spawns only[/color]

[color=#D4D4D8][b]Cycle a placed statue/decoration[/b] (not numpad — reticle-targeted, same as despawn):
] — Cycle the targeted statue or decoration forward through its own roster, in place (undo-able)
[ — Cycle it backward instead[/color]

[color=#D4D4D8][b]Decorations[/b]:
' (apostrophe) — Change the active decoration category: nature, boats, wrecks, tents, storage, furniture, plus 18 themed Drops categories (announces which one on-screen; doesn't place anything)
; (semicolon) — Place one decoration from the active category (cycles its own list, same as the other placement keys)[/color]

[color=#D4D4D8][b]Live-edit[/b] — tunes the nearest placed piece; persists:
PageUp / PageDown — Raise / lower
Comma / Period — Rotate the currently-selected axis left / right (X/Y/Z = Roll/Pitch/Yaw; starts on Z)
/ — Cycle which axis Comma/Period rotate (X -> Y -> Z -> X), toast-confirmed
Num / — Rotate a fixed 45° (Yaw)
Num * — Rotate a fixed 180° (flip in place, Yaw)
Arrow keys — Slide forward / back / left / right
Num - — Cycle precision for the slide/height keys: full / 1/2 / 1/4 / 1/8 / 2x
Num + — Toggle target lock: pin despawn (Num 9), ]/[ cycle, and every live-edit key above — plus the GUI's move panel/Despawn/Coords/Replace — to the object in front of you, so they keep hitting it even after you walk away or look elsewhere. Press again to release; auto-releases if the locked object gets despawned, or if you walk more than ~15m away from it. Always active regardless of In-Game Keys, since the GUI depends on it.[/color]

[color=#D4D4D8][b]Housekeeping[/b]:
Delete (x2) — Clean house: despawn everything (press twice within a few seconds to confirm)
Insert — Toggle LivingBase's own keyboard keys on/off (does not affect the GUI). Starting state configurable in config.txt, off by default.[/color]

[color=#D4D4D8]Remap anything by editing Config.KEYS in Scripts\config.lua.[/color]

[size=4][b]Optional: Windrose Mod Settings Support[/b][/size]
[color=#D4D4D8]If you also have [url=https://www.nexusmods.com/windrose/mods/442][b]Windrose Mod Settings[/b][/url] by [url=https://www.nexusmods.com/windrose/users/77413713][b]IceBoxStudio[/b][/url] installed, Living Base Enhanced registers itself with it automatically — no setup needed. Every key this mod binds, plus several feature toggles, become editable from the game's native Settings > Mods screen instead of hand-editing config.lua/config.txt.[/color]

[color=#D4D4D8]Entirely optional both directions: Living Base Enhanced works exactly the same without Windrose Mod Settings installed, and Windrose Mod Settings works fine without this mod. See Known Limitations below for a stability note.[/color]

[size=4][b]Known Limitations[/b][/size]
[color=#D4D4D8]
- The GUI's mouse cursor stays confined to the game window until one click inside it, after =/- releases it. To fully return to normal camera control: click once in the game window, press = (or -) again if needed, then click once more. Alt+Tab or the Windows key also fully frees the OS cursor as a side effect.
- Because it's an unofficial mod, a game patch can change internal class paths and temporarily break a feature. Everything version-dependent lives in config.lua, so fixes are quick once paths are updated.
- The posed statue keys (Num 3-6) place static actors on purpose — that's the feature, not a bug.
- Arrows, PageUp/PageDown, and the numpad operator keys (/ * -) aren't in this UE4SS build's normal key table and only work via a raw-key-code fallback — the engine drops most rapid repeat presses for these specific keys before UE4SS ever sees them. Individual, deliberate taps land reliably; holding/mashing won't give smooth continuous movement. The GUI's move panel buttons don't have this problem. This is an engine-level limitation, not a mod bug.
- The Brethren of the Coast "woman" crew re-skin (Num 1) currently has a male body under the female clothing — known, not yet fixed.
- Outfit and hair COLOR can't be changed on any NPC placed by this mod, for any feature — this covers the walking faction-visitor re-skins' uniform colors too (generic rather than faction-matched). Confirmed to be a hard engine limitation (the game only sets color once, when a character is first created behind the scenes) rather than something not yet implemented, so it's not on the to-do list. Skin tone and hairstyle are unaffected and both work fine.
- ] and [ (the statue/decoration cycle keys) share a bind with the game's own "Change Target" combat key. Low-risk in practice — you're not usually cycling statues mid-fight — and Insert disables every key this mod uses instantly if it ever gets in the way.
- If using the optional Windrose Mod Settings integration: keybind changes made there need a game restart to fully take effect (a few toggles apply immediately — each one says so in its own description). Separately, moving the mouse cursor quickly over its settings list has been observed to crash the game — this is a Windrose Mod Settings issue, not this mod. Move the cursor slowly there for now.
[/color]
