[size=5][b]Living Base Enhanced[/b][/size]
[color=#D4D4D8]Living Base Enhanced is a base-building and population tool to extend Windrose's native build mode. It allows hand placement of NPCs, decor, plants, animals, monsters and much more. It also allows fine tuned adjustment to those placements both by moving them around and rotating. Additional features allow for customization of clothing and colors and a full photo mode. Keyboard hotkeys and a full GUI window make changes easy to do. All creations and changes are stored persistently outside of the world save, ensuring that no data can be corrupted and uninstalling simply involves removing the mod.[/color]

[color=#D4D4D8][b]Uninstall Instructions[/b][/color]
[spoiler][list]
[*][color=#D4D4D8]Automatic: If installed with Vortex, uninstall may be completed using it. Any persistence and temporary files in the [b]ue4ss/mods/LivingBase[/b] folder will not be removed. This is done on purpose to prevent loss of data when attempting a reinstall. These may be removed manually.[/color][/*]
[*][color=#D4D4D8]Manual:[/color]
[list]
[*][color=#D4D4D8][b]..\Windrose\R5\Content\Paks\~mods[/b]: remove all [i]LivingBaseSignFonts-Windows[/i], [i]LivingBaseBarbieRoster-Windows[/i], and [i]SplitFacial-Windows[/i] files.[/color][/*]
[*][color=#D4D4D8][b]..\Windrose\R5\Binaries\Win64\ue4ss\Mods[/b]: Remove both [i]LivingBase [/i]and [i]LivingBaseSpawnMenu [/i]folders.[/color][/*]
[/list]

[size=4][b][u]Changelog - v2.1.7.1 - v3.0.6[/u][/b][/size]
[spoiler][b][size=3][u]ADDED[/u][/size][/b]
[list]
[*][color=#D4D4D8][b]A real drag-and-drop placement system, entirely new.[/b] Spawn or grab-and-relocate any object and it follows your camera live; Confirm locks it in place, Cancel destroys it (or returns it to where it was picked up from), Replace swaps a locked target for a different look in the same spot, Despawn removes it, and Undo reverses the last 20 despawns/moves/replacements. Floor Clipping toggles whether a new placement snaps to the floor or can be positioned freely through it. The GUI is now the only way to drive any of this, via a numpad-only control scheme that works identically in-game or with the GUI focused.[/color][/*]
[*][color=#D4D4D8][b]Thousands of new spawnable entries[/b] — the spawn tree grew from 472 to 2,195 total entries. A single 848-item content batch alone added large new rosters of people, monstrous mobs, and crabs, with many existing and new NPC rosters split into a wandering "(Mobile)" and a frozen "(Idle)" version of each look. Also added: a Senkamati "Original Upright" presentation alongside the original "Wild" look, Shackles and Dead Prisoner 1-3, a full water-features set (flat water planes, fountain flow/spout meshes, solid empty fountains, spray/splash particle effects), ten tables/display trays, three shelves, and Blacksmith feet/hands/legs clothing items, on top of a broad general decor/furniture expansion.[/color][/*]
[*][color=#D4D4D8][b]Four new GUI tabs:[/b][/color]
[list]
[*][color=#D4D4D8][b]Target List[/b] — scan tracked actors within a chosen radius, filtered by category (People/Monsterous/Animals/Decor/Lights/Build Signs/Labels/Placed Signs), listed nearest-first with a "+" to target-lock any one by index and a "Del" to jump straight to the Signs tab for editing. "Mark Target" highlights whatever's locked with a glowing marker or a tracking flame-ring.[/color][/*]
[*][color=#D4D4D8][b]Customize[/b] — spawn a from-scratch custom character: choose sex, Body Type/Origin, and an optional underwear-only look (auto-fits a complete default outfit otherwise), then dress/pose any target-locked actor through Body (skin tone, eye color, physique, height, AI toggle, one-way Make Ghost), Hair (its own Remove option alongside Clothes), Clothes, Belts and Straps (plus Accessories detect/randomize), and Poses and Actions. Decor View/Full Body/Face View camera presets with held-repeat orbit/zoom. Most spawned looks regenerate fresh on every reload like native NPCs; "Save Customizations" pins a specific actor's look so it survives instead.[/color][/*]
[*][color=#D4D4D8][b]Photo Mode[/b] — Tripod/Selfie/First Person camera presets, a directional move pad, FOV, target highlight, a 3-slot portable lighting rig, a frame-by-frame pose scrubber, Hand item dropdowns, and Weather and Time Set (pick any weather type; freeze the clock at a chosen hour, with an Unfreeze checkbox to resume). Not persisted by design.[/color][/*]
[*][color=#D4D4D8][b]Signs/Labels[/b] — aim at a sign-capable object and press Delete (or click Select Object) to select it, type up to four lines, then Apply/Clear/Reset; text fills the board automatically and is saved/restored per world. Three fonts, a ten-preset color picker, and an "Add Glow" option. A new "Additional Items" roster (Sign Post, Wall Flags, Boards, Obelisk) to place purpose-built signs anywhere.[/color][/*]
[/list]
[/*]
[*][color=#D4D4D8][b]Resource nodes[/b] (shipwrecks, boulders) are now protected from being mined/salvaged.[/color][/*]
[*][color=#D4D4D8][b]Structure shield (PROTECT_STRUCTURES) restored[/b] — building blocks are invulnerable to damage by default (config.txt toggle), independent of the long-removed Blackbeard raid it was originally tied to.[/color][/*]
[*][color=#D4D4D8][b]config.txt reached full parity with Windrose Mod Settings[/b] — every rebindable keybind can be set directly via [size=2][font=Monaco, Menlo, Consolas, monospace][i]KEY_<name> = <UE4SS key name>[/i][/font][/size] lines.[/color][/*]
[/list]
